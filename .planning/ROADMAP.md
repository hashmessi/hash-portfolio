## Assigned Agent Roster & Skill Matrix

1. **Agent 01: Principal Software Architect & Product Strategist (`/brutal-product-engine`)**
   - **Role:** Owns system boundaries, project data contracts (`projects.ts`), Next.js App Router configuration, SSR/client boundaries, and ruthless scope control.
   - **Verification:** Type safety, strict component contracts, zero bloat, build integrity.
2. **Agent 02: Lead Impeccable Design Engineer (`/impeccable`)**
   - **Role:** Owns typography hierarchy (Inter + JetBrains Mono), Apple/Meta spatial layouts, Gumroad tactile button/card press mechanics, and pixel-perfect dual-mode theming.
   - **Skills:** `shape`, `typeset`, `colorize`, `layout`, `polish`.
3. **Agent 03: Motion & SVG Systems Choreographer (`/impeccable animate`)**
   - **Role:** Implements Lenis smooth scrolling, GSAP ScrollTrigger pinning, and the 4 interactive SVG state machines (Trust Dial, Firewall Gate, Promise Receipt Seal, Blast Radius Topology).
   - **Verification:** 60 fps on GPU, zero layout shift, `prefers-reduced-motion` fallbacks.
4. **Agent 04: Hostile Reviewer & Verification QA Lead (`/gsd-ui-review`)**
   - **Role:** Runs the 6-pillar UI review, accessibility audits (WCAG 2.1 AA), responsive mobile testing (375px–1440px), cross-theme contrast checks, and Lighthouse performance auditing.
