A runtime firewall for AI agents that blocks unsafe actions before they execute.

Step 03, a DELETE call, was blocked by rule SEC-403. Gate closed.

Agent tool calls, checked one by one

Gate closed. Violation SEC-403, the action never ran.

Simulate

The problem. Agents now have access to databases, APIs and infrastructure. A single bad tool call, or a chain of harmless-looking steps, can leak data or trigger an operation nobody approved.

What I built. ChainBreak sits between the agent and its tools. It watches the agent's whole sequence of actions, checks each step against security rules, and returns a decision to ALLOW, BLOCK or HOLD the step for a human.

Stack
Python, FastAPI, React, Custom Policy Engine, Web3.js

Key decision
Enforcement is deterministic. A guardrail that an LLM can be argued out of is not a guardrail.
Outcome 01
Causal lineage tracking that follows sensitive data across multi-step action chains
Outcome 02
Deterministic security rules, with no LLM 'judge' that an attacker could talk past
Outcome 03
An adversarial test suite plus trajectory replay to reproduce and audit every decision
Extension: ChainBreak-Web3
I applied the same model to blockchain agents. Before a transaction is signed, it checks the recipient, asset, contract method, calldata and multi-step spending limits against what the user actually authorized. GitHub for ChainBreak-Web3 (opens in new tab)
